# ProizvodPM.02

Данный репозиторий содержит документацию и программные материалы по проекту **ProizvodPM.02**. Здесь представлены исходный код, презентация и вся необходимая отчётная документация.

## Структура репозитория


## Содержимое

### 1. Документация (`/Документы`)

Папка `/Документы` содержит официальную проектную документацию в двух форматах: редактируемом (`.docx`) и для печати/просмотра (`.pdf`).

| Файл | Описание |
| :--- | :--- |
| `Аттестационный лист` | Аттестационный лист (подтверждение выполнения работы). |
| `Дневник` | Дневник практики / журнал работ. |
| `Отчет` | Основной отчёт по проекту. |
| `Пояснительная записка` | Пояснительная записка (описание архитектуры и принятых решений). |
| `Руководство оператора` | Руководство пользователя / инструкция по работе с программой. |

### 2. База данных (`GazProm.sql`)

Файл `GazProm.sql` содержит SQL-скрипт для развёртывания базы данных проекта. В нём представлены:

- Структура таблиц (схема данных)
- Связи между таблицами (внешние ключи)
- Начальные данные (INSERT-запросы)
- Хранимые процедуры и функции (при наличии)

Для развёртывания базы данных выполните данный скрипт в вашей СУБД (например, PostgreSQL, MySQL или Microsoft SQL Server).

### 3. Презентация (`Презентация.pptx`)

Презентация в формате PowerPoint, предназначенная для защиты проекта или промежуточного отчёта.

### 4. Программное обеспечение (`Программа.zip`)

ZIP-архив, содержащий исполняемый файл или исходный код разработанного приложения.

## Начало работы

1.  Склонируйте репозиторий.
2.  Распакуйте `Программа.zip` для доступа к программе.
3.  Выполните SQL-скрипт `GazProm.sql` для создания и наполнения базы данных.
4.  Ознакомьтесь с `Руководством оператора` в папке `Документы` перед запуском.
